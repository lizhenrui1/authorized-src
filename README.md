# authorized-src
面向授权安全测试的漏洞挖掘工作流技能，用于 SRC / 众测 / Bug Bounty / 委托渗透测试场景。当用户提供已获授权的目标（域名、IP、API、App 后端等）并希望系统性推进信息收集、资产枚举、漏洞测试与报告产出时使用。覆盖 Web 常见漏洞类型（注入、XSS、SSRF、RCE、越权、逻辑缺陷、文件上传、路径穿越、认证绕过、GraphQL、竞态、配置缺陷等）。内置强制授权校验门禁、操作红线约束、结构化 playbook、payload 速查、WAF 绕过变体、组件指纹字典与 CVSS 4.0 报告模板。仅在目标具备明确授权时使用；未经授权的目标一律拒绝执行。
